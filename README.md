# QR Code Tools – Online QR & Barcode Toolkit

[![Live Site](https://img.shields.io/badge/Live_Site-QR_Code_Tools-0066ff?style=flat-square)](https://qr-code-tools.2bd.net/)
[![Official Ecosystem](https://img.shields.io/badge/Brand-MRS_Engineers_BD-0ea5e9?style=flat-square)](https://mrs-engineersbd.blogspot.com/)

A modern, fast, and 100% client-side QR Code and Barcode utility suite developed and maintained by **[MRS Engineers BD](https://mrs-engineersbd.blogspot.com/)**. 

---

## ⚡ Key Features

- **Privacy-First (Zero Server Uploads):** All encoding, rendering, and decoding operations run entirely inside your browser. No personal data ever leaves your device.
- **Custom QR Generator:** Supports custom branding, vector SVG/PNG export, error correction levels, custom colors, and styled corner markers.
- **Multi-Format Barcode Engine:** Generate 12+ standard industrial 1D & 2D formats including Code128, EAN-13, UPC-A, Code39, ITF, MSI, and Pharmacode.
- **Live Camera & Image Scanner:** Instant client-side scanning from device camera or uploaded image files.
- **Batch Export:** Download generated codes in single or batch modes without any sign-up or subscription.
